    Prediction Approach & Limitations

    Target: Payment Status — Paid / Partial / Pending, framed as a Non-Payment Risk score (P(Partial)+P(Pending)).

    Model: Multinomial (softmax) logistic regression, trained from scratch in JavaScript via gradient descent — no server, no external ML library. Features are standardized; categorical fields (course, batch) are one-hot encoded.

    —

    Tech Stack & Deployment
    • Single file: everything — HTML, CSS, JS, and the starter dataset — lives in this one index.html.
    • Charts: Chart.js (CDN).
    • Excel upload: SheetJS / xlsx.js (CDN) reads .xlsx/.csv directly in the browser.
    • Model: hand-written softmax regression — trains in under a second on page load.
    • Deploy: upload this file to a GitHub repo, then enable it under Settings → Pages. No build step, no backend.
